# Jarvis (Android)

"Hey Jarvis" म्हणा, तो तुम्ही बोललेले परत ऐकवतो, आणि फोनवर काम करतो: ॲप उघडणे, कॉल, WhatsApp, अलार्म, टायमर, नकाशा, YouTube शोध, फ्लॅशलाइट, आवाज, नोट्स, आणि स्क्रीन वाचून टॅप/स्क्रोल/टाइप.

## APK कसा बनवायचा

**पर्याय 1: Android Studio (PC वर)**
1. Android Studio उघडा, Open → या फोल्डरची निवड करा, Gradle sync होऊ द्या.
2. Build → Build APK(s). फाइल: `app/build/outputs/apk/debug/app-debug.apk`.
3. APK फोनवर पाठवून इन्स्टॉल करा (अज्ञात स्रोतांची परवानगी द्यावी लागेल).

**पर्याय 2: PC नसेल तर GitHub**
1. हा प्रोजेक्ट तुमच्या GitHub रेपोमध्ये टाका (`main` ब्रँच).
2. Actions टॅब → "Build APK" → Run workflow.
3. संपल्यावर `Jarvis-debug-apk` डाउनलोड करा, आत `app-debug.apk` आहे.

## पहिल्यांदा सेट करणे
1. ॲप उघडा, माइक आणि सूचना परवानगी द्या.
2. **सेटिंग्ज** → Anthropic API key टाका (console.anthropic.com वर मिळते). मॉडेल आधीच भरलेले आहे.
3. **सेटअप** मधील चार गोष्टी चालू करा (✔ दिसेपर्यंत):
   - संपर्क आणि कॉल परवानगी
   - इतर ॲप्सवर दाखवा (स्क्रीन बंद असताना ॲप उघडण्यासाठी)
   - बॅटरी ऑप्टिमायझेशन बंद
   - Accessibility सेवा: फोन सेटिंग्जमध्ये Jarvis चालू करा. Android 13+ वर आधी App info → ⋮ → "Allow restricted settings" करावे लागते.
4. **Jarvis चालू करा** दाबा. नोटिफिकेशन दिसेल. आता "Hey Jarvis, YouTube उघड" म्हणा.

## मर्यादा (खरे सांगायचे तर)
- **फोटो/व्हिडिओ तो स्वतः एडिट करत नाही.** तो तुमचे एडिटिंग ॲप उघडतो आणि स्क्रीनवरची बटणे दाबत जातो. गुंतागुंतीचे एडिट अचूक होणार नाही.
- **Send, Pay, Delete, Buy** सारखी बटणे तो तुमच्या स्पष्ट "हो" शिवाय दाबत नाही. WhatsApp/SMS मध्ये मजकूर भरून देतो, send तुम्ही दाबता.
- वेकवर्ड हा फोनची system speech recognition वारंवार चालवून ओळखला जातो (खऱ्या ऑफलाइन वेकवर्ड इंजिनसारखा नाही). म्हणून:
  - बॅटरी जास्त खर्च होते आणि इंटरनेट लागते.
  - काही फोनवर प्रत्येक वेळी लहान बीप ऐकू येऊ शकतो.
  - गोंगाटात कधी कधी ओळखत नाही; जवळ आणि स्पष्ट बोला.
- Android 15 सारख्या नव्या आवृत्त्यांत स्क्रीन बंद असताना ॲप उघडणे अडवले जाऊ शकते. तेव्हा "टॅप करा" नोटिफिकेशन येते.
- मराठी आवाज फोनच्या Text-to-speech इंजिनमध्ये नसेल तर हिंदी किंवा इंग्रजी वापरतो. सेटिंग्ज → Text-to-speech मधून मराठी डाउनलोड करा.

## गोपनीयता
- तुम्ही बोललेला आवाज Google च्या speech service कडे जातो (फोनचे recognizer).
- तुमचे शब्द, इन्स्टॉल केलेल्या ॲप्सची नावे, आणि `read_screen` वापरला तर स्क्रीनवरचा मजकूर Anthropic API कडे जातो. बँकिंग किंवा खाजगी स्क्रीनवर Jarvis वापरू नका.
- API key फक्त ॲपच्या खाजगी स्टोरेजमध्ये राहते.

## कोडची रचना
`Ear` वेकवर्ड ऐकतो → `Core` आदेश घेतो → `Brain` Claude ला विचारतो (tool use) → `Actions` / `JarvisAccess` फोनवर काम करतात → `Speaker` उत्तर वाचतो.
